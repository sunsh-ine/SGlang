整体框架

SGLang 运行时架构

调用方 → HTTP Server → TokenizerManager → Scheduler → TpModelWorker → KV Cache 的请求主路径， 以及返回链路 Scheduler --BatchTokenIDOutput--> DetokenizerManager --BatchStrOutput--> TokenizerManager --文本分片--> HTTP Server SSE； 采样出的 next_token_ids 回到 Scheduler，KV 池的写入与读取分成两条边。 另含进程/通信拓扑（ZMQ IPC）、前缀缓存复用、KV 显存池与鉴权信任边界。

Scheduler 调度主循环

一轮迭代的完整过程：上游收到什么（已分词请求与批量请求），如何入队与组批， 下发什么（ScheduleBatch → 前向、BatchTokenIDOutput → Detokenizer、PD 的 KV 搬运）， 以及显存不足时的抢占回退。

components/sglang-scheduler-loop.html workflow 源 JSON

Scheduler 同步 / Overlap：CPU–GPU 时间线

同一个调度循环的两种写法：event_loop_normal 里 CPU 阻塞等 GPU 算完， GPU 在 CPU 组批与结算期间全部空转；event_loop_overlap 里 run_batch 只下发， CPU 等上一批返回并处理结果的同时 GPU 已在算当前批 —— 同样 3 批，30 → 22.5 单位（示意刻度）。

请求往返：请求下行与 token 回流

端到端六方时序：客户端 → HTTP Server → TokenizerManager →（ZMQ）Scheduler → TpModelWorker； 回程 BatchTokenIDOutput（只有 token ids）→ DetokenizerManager 增量解码 → BatchStrOutput → TokenizerManager 写回 out_queue → SSE 到客户端。 另标出断连 abort 与控制类回包这条反向通道。

components/sglang-request-roundtrip.html sequence 源 JSON

TokenizerManager：进来、下发、回包

单看主进程里的 TokenizerManager：HTTP 进来后建 ReqState 并登记 rid_to_state、 过 pause 门与权重读锁、分词校验，再组 TokenizedGenerateReqInput 经 ZMQ 单向下发； 回程由 handle_loop 异步收 BatchStrOutput，按 rid 写 out_list + event， 等待循环 drain 后 yield 给 StreamingResponse；断连则 AbortReq 回到 Scheduler。

components/sglang-tokenizer-manager.html workflow 源 JSON

DetokenizerManager：ids → 文本 → 归位

上游 Scheduler 单向送 BatchTokenIDOutput；进程内 decode_status 保存每请求的 decode_ids 与三个偏移，surr 与 read 两段各解一次、取差就是新增文本 （半个 UTF-8 字符只发可打印前缀、下轮重试）；组好 BatchStrOutput 后单向推给 TokenizerManager，多 worker 时按 http_worker_ipc 定向。图里标明了唯一的双向关系： decode_status 的读写。

components/sglang-detokenizer-manager.html workflow 源 JSON

TpModelWorker：一次前向的打包、执行、回传

和 Scheduler 同进程、每 TP rank 一个：每个 rank 都跑本份 GPU 计算（attention/MLP 切片 + 每层 all-reduce / all-gather 集合通信），init_new 把 ScheduleBatch 打包成 ForwardBatch （input_ids / positions / out_cache_loc）；命中就重放 CUDA Graph、否则 eager。 只有 PP 末段出 logits 并采样（TP 下 all-gather 后各 rank 独立采样结果一致），overlap 下改成 delay_sample_func 由 Scheduler 触发；KV 池读写、spec verify / prefill-only 不采样也标了。
