准备开始

点击播放或“下一步”，观察 A、B、C 如何在同一棵树上插入和分裂。

插入 A

整条 token 序列作为一条边写入，生成一个根的子节点。

匹配 B

命中 3 个 token；原节点在匹配边界分裂为 [10,20,30] 与 [40,50]。

插入 B

公共前缀的 KV 直接复用，只把新增后缀 [60,70] 写入新节点。

插入 C

只命中 2 个 token；再次分裂，[80,90] 与 [30] 并列为子节点。

示例：A = [10,20,30,40,50] · B = [10,20,30,60,70] · C = [10,20,80,90]。节点标签在原位变化，新增/分裂只让对应节点和连线淡入。
