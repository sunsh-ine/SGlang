RADIXATTENTION / KV CACHE

Radix Tree 的请求插入过程

请求 A、B、C 依次到达运行时：先在基数树中做前缀匹配，再只把未命中的后缀写入新节点。被命中的前缀直接复用已有 KV，无需重新 prefill。

  1. 01插入 A
  2. 02匹配 B
  3. 03插入 B
  4. 04插入 C
←/→ 切换 · 空格 播放/暂停 · R 重播 · Home/End 跳转 第 4 / 4 步

示例序列：A = [10,20,30,40,50] · B = [10,20,30,60,70] · C = [10,20,80,90]。节点里的方括号表示一段连续 token；命中前缀的 KV 槽位被复用，只有未命中的后缀参与本轮 prefill 并写入新节点。
