从 Root 查找第一条分支

请求 B 以 Token 10 开始，找到以 [10,20] 开头的缓存节点。

第一个节点完全匹配

[10,20] 与请求 B 的前两个 Token 完全一致，累计命中长度为 2，继续向下查找剩余的 [30,60,70]。

第二个节点部分匹配

沿 Token 30 分支找到 [30,40,50]，其中只有 [30] 与请求 B 相同，累计命中长度为 3。

匹配结束并确定结果

匹配终点位于压缩节点内部，需要将 [30] 分裂成独立节点。返回长度 3 和最后匹配节点，但不插入 [60,70]。

匹配到压缩节点内部时，节点在匹配边界处分裂：原节点保留 [30]，剩余后缀 [40,50] 成为其子节点。命中长度是 3，未命中的 [60,70] 本轮不插入。
